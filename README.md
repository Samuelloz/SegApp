# SegApp

Software para gestión de seguridad privada.

## Descripción
SegApp es una plataforma para administrar personal operativo (guardias),
contratos y operaciones de empresas de seguridad privada.

Está diseñado como un producto SaaS escalable para empresas de seguridad privada.

## 🚀 Stack
- Frontend: Next.js (App Router) + TypeScript
- Backend: NestJS + Prisma
- Estado: Redux Toolkit + RTK Query
- UI: Componentes propios + Sonner (toasts)
- Monorepo: PNPM Workspaces

## 🧱 Estructura

apps/
- api/   → Backend (NestJS)
- web/   → Frontend (Next.js)

## Requisitos
- Node.js 18+
- PNPM
- Docker (opcional)

## ⚙️ Setup

pnpm install  
pnpm dev
